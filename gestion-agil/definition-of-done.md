# Definition of Done

Una historia se puede cerrar cuando se cumplen las condiciones que le aplican:

- Cumple sus criterios de aceptación y se enlaza a la historia/issue correspondiente.
- El código y la configuración están en el repositorio, con instrucciones para reproducirlos.
- Los cambios de configuración tienen revisión del equipo y usan nombres/valores coherentes con el caso AgroSugar.
- La validación enlazada identifica entorno, comando, fecha y resultado. Una simulación se etiqueta como simulación.
- Las capturas son originales y no muestran secretos; las salidas esperadas no se presentan como salidas medidas.
- Se actualiza el README o la documentación técnica afectada.
- Los puntos no probados se registran como pendientes, junto con el impedimento o la siguiente acción.

Para historias de desempeño, disponibilidad, latencia, escalado o PUE, `Done` requiere datos medidos en el entorno que indican sus criterios. Una configuración propuesta por sí sola no cumple ese criterio.
